# Доработка существующих сценариев — 19.10.2026

Основание: пользователь согласовал вариант 2 и порядок «создание заметки → карточка места → коллекции → обмен и импорт → общая визуальная полировка».

Связь с требованиями: NOTE-FR-001..005; существующие сценарии коллекций, независимого импорта и ручного обновления. Категории, приватность и внешний контракт не меняются.

- Редактор: оценка 1–10 или без оценки; текст, категория, дата и выбранные фотографии сохраняются одним действием. Подготовка фотографий последовательная; транзакция IndexedDB сохраняет заметку и фотографии атомарно. При ошибке выбранные фото остаются в редакторе. Существующие фото видны в редакторе; удаление доступно в разделе «Фото».
- Карточка: основные действия «На карте / Изменить / Поделиться», остальные — в меню; отдельный возврат из обмена и выбора коллекции. Просмотр фотографий внутри приложения.
- Места: переключатель «Все / Лучшие / По предмету». Категории выбираются сверху, без дублирования в дополнительных фильтрах.
- Коллекция: пакетный выбор сохранённых личных мест с поиском. Проверка существования всех выбранных заметок до изменения; одна транзакция, повторные ID не создают дубликатов.
- Обмен: ссылка на 7 дней — основной путь для коллекции; файл без фото и история — дополнительные разделы. Правила доступа доступны перед публикацией. Параметры включения приватных полей не меняются.
- Импорт: единый блок обложки, автора, карты и списка мест для файла и облачной ссылки. Сохраняется независимая копия; обновление по новой версии требует прежнего diff и подтверждения.
- Оформление: общие размеры контролов, закреплённое сохранение, читаемые подписи, поддержка reduced motion и safe area.

Проверка: релевантные тесты хранения/обмена и production-сборка. Визуальная проверка реального телефона остаётся необходимой: браузерный инструмент заблокировал доступ политикой.


## Уточнение: только ссылки

Пользователь отменил обмен файлами. В интерфейсе коллекций больше нет выбора файла, скачивания snapshot или истории файлов. Личные резервные копии в профиле — отдельная функция восстановления данных.

Коллекции разделены на «Мои» и «Полученные». Импорт начинается кнопкой «Открыть ссылку», переход — только к проверенному токену Notemap, без перехода на произвольный внешний сайт. Обмен использует компактные доступные переключатели, системное меню отправки и копирование; правила доступа раскрываются отдельно. Приватные поля по умолчанию выключены, выбор фото сохранён.

Отдельное место публикуется в поддерживаемом облаком формате коллекции с одним элементом, без создания новой личной коллекции и без изменения внешнего контракта. Исходный ID сохраняется для ручного обновления ранее импортированной копии.


## Единые выпадающие списки

Системные select заменены общим компонентом: категория заметки, предмет, минимальная оценка, коллекция и режим поиска. Меню выводится через portal поверх прокручиваемых панелей, учитывает доступную высоту и направление открытия. Поддерживаются клавиатура, поиск по набранному тексту, отметка выбора, Escape, Tab и нажатие вне меню; сенсорная прокрутка не меняет подсветку пунктов. Реальная проверка на Android/iOS остаётся отдельной проверкой устройства.


## Предпросмотр общей ссылки

Страница сохранения подборки: компактная шапка с обложкой, Яндекс JS API вместо прежней Geoapify-подложки, раскрываемые места, короткая подпись о независимой копии и закреплённая кнопка сохранения. Пустая подборка не создаёт экземпляр карты и не предлагает сохранять пустую новую копию. Подтверждение diff для существующей копии по-прежнему допускает явное удаление всех импортированных мест. Ошибка карты не блокирует просмотр списка или импорт. Логотип и ссылки Яндекса сохраняются штатными.


## 20.10: название в плашке карты

Нажатие «Добавить место» раскрывает многострочное поле прямо в той же плашке; фокус устанавливается синхронно из пользовательского нажатия. Поле автоматически увеличивается до ограниченной высоты, затем прокручивается; лимит названия — прежние 200 символов. «Добавить точку» сразу создаёт личную запись без оценки в категории «Другое» на исходной координате. Повторный запрос с теми же данными использует тот же ключ, ошибка сохраняет текст для повтора. Клавиатура учитывается через visualViewport; обработчики снимаются при закрытии. Пункт «+» нижней навигации сохраняет прежний ручной выбор точки. Реальная клавиатура Android/iOS требует проверки устройства.


## 23.10: релевантность поиска и маркеры результатов

PLACE-FR-001, MAP-FR-005: организации ищутся через Geoapify Places по имени или известной категории (кафе, рестораны, аптеки и т.д.), в радиусе текущей области 1–50 км. Адресный поиск остаётся отдельным геокодированием. При пустом именованном ответе Places выполняется один резервный поиск amenity; совпадение имени, ID, координаты и радиус проверяются до показа. Адреса и далёкие совпадения не подставляются вместо организаций. Резервный запрос также расходует бесплатный лимит; пауза между запросами отменяема.

Результаты — отдельные нумерованные маркеры и строки списка с одинаковыми номерами. Выбор выделяет точку и открывает карточку, ручное сохранение — прежним проверенным путём. После поиска камера охватывает результаты; кнопка «Искать здесь» явно повторяет запрос после перемещения карты. Нет запросов при каждом движении карты, автозапроса GPS или изменений личных заметок.

Во время обновления прежняя выдача сохраняется под своим названием; устаревшие запросы отменяются. Вместо десятков растровых мини-карт в строках отображаются номера. До 30 ответов кешируются в памяти на 5 минут; кеш не передаётся в облако и не создаёт постоянную историю запросов. Существующий лимит 50 обращений в сутки на устройство сохранён. Проверены реальные публичные запросы в Москве: категория кафе, именованный запрос Places и резервное amenity-геокодирование. Полнота справочника Geoapify не равна Яндексу; точность конкретных организаций зависит от данных поставщика.
